## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ToobaSubhan/Tariq-mehmood-portfolio.git
cd Tariq-mehmood-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

## 📦 Build

To build the project for production:
```bash
npm run build
```

## 🌍 Deployment

This portfolio is deployed on Cloudflare Workers. For deployment information, visit the [live site](https://tariq-mehmood-portfolio.toobasubhan444.workers.dev/).
